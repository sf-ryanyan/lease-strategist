## 🧭 这是什么

租管军师是一个 Claude Skill，把加州长租物业管理拆成**首次设置 + 17 个步骤模块 + 3 个贯穿模块**：获客评估、托管合同、接房交接、修缮、上市营销、询盘带看、申请筛选、租约披露、收款入住、账单、维修、收租、租期事务、续约涨租、退租押金、欠租驱逐、结束托管。

每一步都有**清单、模板、关卡和提醒**。你只要把地址、消息或资料贴给 Claude，它会自动进入对应的步骤，给出可以直接复制使用的结果。

## 🎯 解决哪些痛点

| 痛点 | 租管军师怎么做 |
|---|---|
| 不知道这个房子能租多少 | 先问你能拿到哪些数据，再出区域市场、租金三档、法规速查、托管线索评分 |
| 业主对托管合同有很多疑问 | 12 项合同要点检查 + 常见疑虑的回答思路 + 修改建议 |
| 每个平台的文案都要重写 | 一次生成 Zillow、MLS、Craigslist 复制粘贴版，加中英营销套餐（朋友圈、小红书、英文帖子、传单） |
| 敏感问题怕说错（Section 8、服务动物、学区） | 公平住房的标准回复，只描述房子，不描述人 |
| 申请人材料真假难辨 | 身份、收入、雇主、租房历史的核查清单和风险信号，按同一套标准对比 |
| 签约漏签、披露漏给 | 法定披露清单 + 签齐检查关卡 |
| 维修来回沟通、费用说不清 | 分级、定责任、按审批上限走流程、给师傅的说明一次讲清楚 |
| 续约、交租、押金期限容易忘 | 多物业 Excel 总控台，自动算出提醒日期，过期未处理的也会列出来 |
| 押金扣款、驱逐通知怕不合规 | 折旧方法、扣款证据表、21 天期限；3 天通知的金额、期限算法和必写内容 |

## ⚙️ 怎么运作

### 1. 按任务分流 —— 只读这次需要的内容
核心文件很小，每一步的内容放在单独的模块里。你说什么，就只读对应的那一个模块和需要的那一段模板。

### 2. 三个级别
- 🟢 **轻量**：询盘回复、交租提醒、进屋通知、简单报修 —— 只读模板，不联网
- 🟡 **标准**：大部分步骤 —— 先发数据清单，联网最多 2 次
- 🔴 **完整**：地址评估、合同审查、申请筛选、押金扣款、驱逐 —— 完整调研和法规核查

### 3. 关卡
合同没签齐不交接；业主没书面选定租客不准备租约；入住款没到账不交钥匙；超过审批上限不派工。

### 4. 提醒和红线警告
打开时列出已过期和 7 天内到期的事项（每条一行）；押金超限、违法驱逐、超过涨租上限、未通知进屋等法律红线直接警告。

### 5. 法规每次核实
附带加州法规清单和湾区城市资料作为起点，用到时去官方来源核实，并写明核实日期；没核实成功就标「未核实」。

### 6. 语言
跟你用中文沟通；给业主的按设置用中文或英文；给租客、看房人、师傅的用英文。

## 🚀 快速开始

### 第 1 步 —— 安装
到 [Releases 下载页](https://github.com/sf-ryanyan/lease-strategist/releases/latest) 下载 zip，在 Claude 里上传为 Skill。

### 第 2 步 —— 直接开始
新开一个对话，直接说你要做的事，比如给一个地址。租管军师会**先做任务**，只问这一步马上要用的 1–2 项信息，其余先用默认值。

### 第 3 步 —— 完整设置（可选，约 5 分钟）
说「设置」，填一份问卷：品牌、broker、DRE 号、收费方式、租金流向（租客直付业主 / 信托账户）、维修审批上限、语言、默认招租标准等。填多少都行，以后可以改。

## 💬 日常怎么用

直接说你要做的事：

- 「123 Main St, San Jose 能租多少？业主想托管。」
- 「业主问能不能随时解约，怎么回？」
- 「帮我写 Zillow、MLS 和朋友圈的上市文案，再做一张传单」
- 「Zillow 上有人问接不接受 Section 8，还有一只情感支持狗，怎么回？」
- 「收到 3 份申请，帮我对比」
- 「租客说厨房水槽下面一直漏水」
- 「租约 1 月底到期，业主想涨租，最多能涨多少？」
- 「租客搬走了，帮我做押金扣款明细」
- 「租客 10 月租金没交，3 天通知写多少钱、哪天截止？」
- 「这周我要做什么？」

## 📋 总控台

有项目文件夹时（Claude 桌面版或 Claude Code），租管军师会把数据存在 `租管数据/`：

| 内容 | 说明 |
|---|---|
| `总控台.xlsx` | 11 张表：物业总览、联系人、租约、询盘看房、申请人、维修工单、租金记录、账单、待办提醒、师傅名单、使用说明。续约提醒日、押金退还截止、工单应完成日、调价检查日自动计算 |
| `设置.md` | 你的设置卡片 |
| `法规缓存/` | 核实过的城市规定和核实日期 |
| `物业/{地址}/` | 每个物业的记录和文件夹 |

网页聊天没有文件夹时，每次结尾给你一张「物业卡片」，下次粘贴回来就能接着做。

## 💡 省 token 的设计

- **核心文件很小**，具体内容放在模块里，每次只读需要的那一个
- **模板和资料按段读**，不整份读
- **先发数据清单**：你有 MLS 或其他数据就给，没有再有限联网
- **联网次数按档位控制**，法规核查也算在内；核实过的规定存进缓存，90 天内直接用
- **提醒每条只提示一行**，你说「做」才展开

---

## 🚧 限制

- **不会连接** MLS、Zillow、筛选平台或电子签工具。需要你把资料贴给 Claude，再把结果复制回去。
- **对话之间没有记忆。** 有文件夹时数据存在总控台；没有文件夹时要自己保存物业卡片。
- **只适用于加州长租**（以湾区为主）。不含短租 / Airbnb、租客找房顾问、房屋买卖估值。
- **测试版：** 已用虚构场景完整测试，但还没有覆盖所有真实业务情况。
- 法规会变。租管军师会去官方来源核实，或告诉你要核实什么；官方网站打不开时会标「未核实」。
- 它只起草，从不发送。每条消息、每份文件都由你确认后发出。
