# M05 — 上市信息 + 各平台文案 + 中英营销套餐 + 发布

**用量**：🟡 标准 · **触发**：上市、写文案、Zillow、MLS、Craigslist、Facebook、传单、朋友圈、小红书、群发。

目标：管理者拿到就能**复制粘贴直接发**。

## 第 1 步：上市信息问卷（没填的先问）

| 项目 | 内容 |
|---|---|
| 地址（公开到什么程度：完整地址 / 只写街区） |  |
| 月租金、押金（所有押金类费用合计不超过上限） |  |
| 可入住日、租期（12 个月 / 月租 / 其他） |  |
| 几室几卫、面积、类型、楼层 |  |
| 宠物政策（注明：服务动物和情感支持动物不算宠物） |  |
| 水电谁付 |  |
| 车位、洗衣、空调、暖气、家电（含炉灶、冰箱） |  |
| 亮点（最多 5 个，只写事实） |  |
| 学区（只写学校名，并写「请向学区核实」） |  |
| 看房方式和可约时间 |  |
| 申请方式、申请费、筛选标准摘要、选择方式（来自 M04 第 7 步） |  |
| 联系人、品牌、broker 和 DRE 号（来自 M00） |  |
| 照片是否已拍好、有没有视频或 3D 看房链接 |  |

## 第 2 步：拍照清单（如果还没拍）

- 清洁完成后、光线好的时候拍；横拍；广角不要变形；不拍个人物品和人
- 顺序：外观主图 → 客厅 → 厨房 → 主卧 → 卫生间 → 其他卧室 → 院子 → 车位 → 社区或周边
- 可选：视频、3D 看房、平面图
- 加水印，防止被骗子盗用照片

## 第 3 步：生成各平台的复制粘贴版

| 平台 | 生成内容 |
|---|---|
| **MLS** | 公开备注（按用户 MLS 的字数限制；公开备注里一般不能放联系方式）+ 经纪人备注（看房方式、申请方式、佣金或合作费按用户提供） |
| **Zillow** | 标题 + 描述 + 按 Zillow 字段顺序列出的设施和政策（会同步到 Trulia、HotPads） |
| **Craigslist** | 标题 + 正文 + 防诈骗声明 |
| **Facebook Marketplace / Apartments.com / 自己的网站** | 按平台格式 |

每个平台都给 **3 个标题备选**。

## 第 4 步：中英营销套餐

- **中文**：微信朋友圈（短，配 9 张图的顺序建议）· 微信群发（更短，带看房和申请方式）· 小红书（标题 + 正文 + 话题标签）
- **英文**：Facebook / Nextdoor 帖子 · LinkedIn 帖子（适合靠近大雇主的房子）
- **传单（flyer）**：一页，放主图 + 3–4 张小图、租金、几室几卫、可入住日、3–5 个亮点、看房和申请方式、联系方式、品牌和 broker / DRE 号；可以加看房或申请二维码（用户提供链接）。确认文字后，生成可打印的页面或 PDF
- 中文版不是逐字翻译，用自然的中文写同样的事实

## 第 5 步：发布前检查

**公平住房用词**（每份都过一遍）
- ❌ 不写：「适合情侣 / 年轻专业人士 / 小家庭」「不要小孩」「成熟稳重」「安静的租客」「不接受 Section 8」「必须有工作」、宗教或国籍相关的词、「身体健全」、「不接受任何动物」
- ✅ 改写成事实：「三楼无电梯」「步行 0.4 英里到轻轨站」「学区：X 小学（请向学区核实）」「收入为租金的 X 倍或同等证明，欢迎住房券」
- 检查结果写：**通过** / **改了哪些词**

**其他**
- [ ] 所有平台信息一致（租金、押金、日期、政策）
- [ ] 押金和申请费符合规定（X3 快速检查）
- [ ] 防诈骗声明：「本房源只由本人或本公司带看和收申请；看房前不会收任何款项；所有付款方式都会电话确认」
- [ ] 品牌、联系方式、broker 和 DRE 号（首次接触的营销材料要写）
- [ ] 筛选标准摘要和书面标准一致

## 输出

各平台复制粘贴版 · 中英营销套餐 · 传单文字（确认后出文件）· 检查结果。管理者发布后，更新总控台：物业总览（状态 = 上市、上市日期）、待办提醒（第 7 / 14 / 21 天检查）。下一步 → M06。
