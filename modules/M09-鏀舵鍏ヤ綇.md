# M09 — 收入住款 + 入住交接 +（只招租）交付包

**用量**：🟡 标准 · **触发**：押金、首月租金、入住款、交钥匙、水电过户、入住检查、欢迎包。

## 第 1 步：入住款计算表

| 项目 | 金额 | 说明 |
|---|---|---|
| 押金 |  | **所有押金类费用合计**（含宠物押金、钥匙押金、预收的最后一个月租金）不超过上限 |
| 首月租金 |  | 月中入住按天折算：月租 ÷ 当月天数 × 入住天数 |
| 其他（按租约） |  | 不属于押金的费用，比如首月宠物租金（服务动物不收） |
| 减：已收意向金 |  |  |
| **合计** |  |  |
| 付款截止日 |  | 一般在交钥匙前 |

发给租客前，先和业主确认金额。

## 第 2 步：收款

1. **问业主想用什么方式收**：本票（cashier's check）/ 银行转账 / Zelle / 其他。按付款模式：A 进业主账户，B 进信托账户
2. **skill 不保存任何账户信息**。只帮忙填好付款通知模板（`templates/T-租客通知.md` 第 1 段），账户信息由管理者自己填
3. ⚠️ **防电汇诈骗**（每次都提醒）：
   - 收款信息要通过电话确认（打已知的号码）
   - 邮件里说「更换收款账户」一律先电话核实
   - 提醒租客：我们不会通过邮件突然改收款信息
4. **跟双方确认**：租客说「已付」→ 业主或信托确认「已收、已到账」（支票要等清算）
5. 需要的话开收据（押金收据写明金额、日期、用途）
6. **模式 A 也要注意**：管理者经手的支票或现金（即使抬头是业主）按 DRE 规定也算信托资金，要记录并在 3 个工作日内交给业主或存入（`references/加州法规清单.md` §13）。最好让租客直接付给业主
7. **海外业主**：租客直接付给海外业主时，租客本人可能要做联邦预扣税 → 提醒业主先把 W-8ECI 等表格给付款方，并问会计（§14）。海外账户收款不方便（比如 Zelle 要美国银行），建议押金放在美国账户或信托账户，确保 21 天能按时退
6. **到账后才交钥匙**（关卡）。没付清 → 发入住前付款通知（C.A.R. PPN）

## 第 3 步：入住前提醒（发给租客，`templates/T-租客通知.md` 第 2 段）

- **水电过户**：列出这个地址对应的公司（先问业主，不知道就按 `references/湾区城市资料.md` 第 2 段联网查）和开户方式；哪些租客开户、哪些业主付
- **租客保险**：入住前提交证明
- **设备移交**：电子锁（改主密码、删除旧用户、把 App 访问权限转给租客或给租客专用密码）、车库遥控、智能恒温器、门铃摄像头（业主的账户要移除或转移，注意隐私）、门禁卡
- 入住当天的时间和流程

## 第 4 步：入住当天

1. 和租客一起做**入住检查**（C.A.R. MIMO 或用户的表格），每个房间**拍照**（可以另加视频），带时间戳；双方签字
2. 抄水电表（拍照）
3. **钥匙签收单**（管理者 → 租客）：每项钥匙、遥控、门禁卡的数量；双方签字
4. 告诉租客：入住后 **X 天内**（M00 设置，常见 7–15 天）可以书面补充他发现的问题

## 第 5 步：入住后

- **15 天内**把签好的租约完整副本给租客；确认租约里已写明管理者、业主或接收法律文件的代理人的姓名和地址，以及交租给谁、怎么交（§1962，`references/加州法规清单.md` §9）
- 发**欢迎包**（`templates/T-租客通知.md` 第 3 段）：怎么交租、报修链接或方式、紧急联系人、垃圾收运日、HOA 规定、水电公司、常见问题
- 租客在补充期内报的问题 → 交给业主决定修不修、找谁修 → 转成**维修工单**（M11）

## 第 6 步：只招租的物业 → 交付包（服务到此结束）

给业主一份交付包：
- [ ] 签好的租约、披露、附件（完整副本）
- [ ] 入住检查报告和照片
- [ ] 钥匙签收单（业主留存部分）
- [ ] 租客联系方式、紧急联系人
- [ ] 押金和首月租金的收款记录
- [ ] 业主接下来要做的事：每月收租、§1962 告知、维修联系、租约到期日、续约提醒
- [ ] 一句提醒：以后租约、押金和维修由业主自己处理

然后 → M10 收租赁费。

## 输出

入住款计算表 · 付款通知草稿 · 收款确认记录 · 入住前提醒 · 入住检查和钥匙签收提醒 · 欢迎包 · （只招租）交付包。

更新总控台：租金记录（首月）、物业总览（状态 = 已入住 / 在管，或只招租的「已结束」）、待办提醒（15 天告知、补充期截止）。下一步 → M10。
