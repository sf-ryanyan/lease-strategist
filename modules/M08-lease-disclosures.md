# M08 — 租约 + 法定披露 + 签齐检查

**用量**：🟡 标准 · **触发**：准备租约；披露文件；签约；「看看签齐没有」；租客或业主对租约有疑问。

## 第 1 步：关卡

- [ ] 业主**书面选定**了这位租客（M07）
- [ ] 租客符合书面标准（或业主书面接受了附加条件）
- [ ] 收意向金（holding deposit）的话，有书面协议写明金额、用途、退还条件；转为押金后和其他押金类费用合计不超过上限

## 第 2 步：租约要点检查清单

用用户自己的租约或 C.A.R. RLMM。逐项确认：

| 项目 | 确认 |
|---|---|
| 承租人 | 所有成年住户都列为承租人；居住人数 |
| 期限 | 起租日、到期日；定期还是月租；到期后自动转月租吗 |
| 租金 | 金额、几号交、交给谁、怎么交（按付款模式 A / B）|
| 宽限期和滞纳金 | 天数；金额是合理估计（不能当罚款）|
| 押金 | **所有押金类费用合计**（含宠物押金、钥匙押金、预收的最后一个月租金）不超过上限（X3 核实）；谁保管 |
| §1962 信息 | 管理者姓名、电话、地址；业主或接收法律文件的代理人的姓名和地址（海外业主建议写管理者或美国代理人）；交租给谁、怎么交 |
| 语言 | 主要用中文谈的、租期超过一个月 → 签约前给中文译本（§1632）|
| 水电 | 每项谁付；共用表要披露 |
| 宠物和动物 | 宠物政策；服务动物不是宠物 |
| 车位、储物 | 写清楚 |
| **维修责任分工** | 草坪、空调滤网、虫害、家电、下水道疏通、报警器电池、灯泡：租客还是业主（写进总控台租约表）|
| 租客保险 | 要求买租客保险（renter's insurance），写明最低责任额，入住前提供证明 |
| 禁止事项 | 吸烟、转租、做 Airbnb / 短租、商业用途 |
| 进屋 | 通知方式（§1954）|
| HOA | 遵守 HOA 规定；HOA 规定作为附件 |
| AB 1482 | 适用的写通知；豁免的写**豁免声明**（2020-07-01 后的租约必须写在租约里）|
| 炉灶和冰箱 | 业主提供；租客自带冰箱的要写明（AB 628）|
| 定期检查 | 要不要写进去（M13 用）|
| 续约和退租 | 续约方式；退租通知天数；退房清洁标准 |

## 第 3 步：法定披露

按 `references/disclosures-forms.md` 第 1 段逐项判断「要 / 不要 / 待核实」。结合 M04 业主知情问卷的回答。**每次签约前核实最新清单。**

## 第 4 步：发给双方

- 签约**前 2–3 天**把租约和全部披露发给租客和业主
- 附**条款解释**：
  - 租客版（英文为主）：每个重要条款用白话说明（租金、押金、维修责任、进屋、宠物、退租）
  - 业主版（按 M00 语言）：重点条款和业主要承担的义务
- 收集双方的疑问 → 解答 → 需要的话修改 → 再发一次

## 第 5 步：签约 + 签后核对

- 电子签（用户的电子签工具）
- **签后核对**：管理者把签好的文件给 skill 看，用 `references/disclosures-forms.md` 第 3 段检查漏签、少签、缺的页和附件 → 列出要补的
- 全部补齐 → 给双方完整副本 → 存到 `01-合同租约/` 和 `02-披露/`

## 输出

关卡结果 · 租约要点检查表 · 披露清单 · 租客版和业主版条款解释 · 签后核对结果。

更新总控台：租约表（全部字段，包括责任分工；续约提醒日会自动算出来）、联系人（租客）、物业总览（状态 = 签租约）。下一步 → M09。
