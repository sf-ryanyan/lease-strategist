# M02 — 托管合同审查 + 业主答疑

**用量**：🔴 完整 · **触发**：托管合同、管理合同、挂牌出租合同；业主对合同有疑问；「帮我写一份托管合同」。

**定位**：本 skill 是**顾问**，帮用户审合同、讲怎么填、指出风险。不替用户出具合同，不给法律意见；复杂或有争议的条款 → 律师或 broker。

## 第 0 步：数据

- 合同文件（用户上传）。**没有文件就不能审**——请用户上传
- 合同类型：全托管（如 C.A.R. PMA）/ 只招租（如 C.A.R. LL）/ 用户自己的版本
- 业主情况：几个产权人、个人 / 信托 / LLC、是否海外业主
- M00 的收费方式和付款模式

**用户要从零写一份**：先联网找公开的模板或要点（C.A.R. 表格只能由会员在 zipForm 里使用；也可以请 broker 提供公司版本）。本 skill 给出**要写进去的条款清单和填写建议**，不生成可直接签的合同原文，并提醒签约前请 broker 或律师看一遍。

## 第 1 步：要点检查（12 项）

| # | 检查 | 看什么 |
|---|---|---|
| 1 | **签约方** | 所有产权人都签了吗？共有人、信托（受托人）、LLC（授权签字人）要有证明 |
| 2 | **期限和终止** | 起止日期；提前终止要提前几天通知；有没有终止费；终止后已签的租约和押金怎么处理 |
| 3 | **服务范围** | 包含什么、不包含什么（驱逐、出庭、大型装修、保险理赔、HOA 会议、财务报税） |
| 4 | **费用** | 租赁费、月管理费、续约费、维修协调费或加价、空置期收不收费、上门费；和 M00 一致吗 |
| 5 | **资金** | 租金流向（A / B）；押金谁保管；备用金（reserve）多少；每月几号打款给业主；报表频率 |
| 6 | **维修授权** | 审批上限多少；紧急情况可以先修；师傅由谁指定 |
| 7 | **保险和责任** | 业主要有房屋保险和责任险；是否把管理者列为附加被保险人（additional insured）；赔偿条款 |
| 8 | **公平住房** | 业主不能要求违法筛选；有这样的要求时管理者可以拒绝 |
| 9 | **代签和代发** | 管理者能不能代签租约、代发通知、代收押金 |
| 10 | **业主披露义务** | 业主必须告知已知的房屋缺陷和问题（连到 M04 的业主知情问卷） |
| 11 | **记录和沟通** | 用什么方式沟通、多久报告一次、文件保存多久 |
| 12 | **争议和执照** | 争议怎么解决；broker 名称和 DRE 号写了没有 |

另外检查：服务类型（只招租 / 全托管）是否写清楚。

**海外业主**另外检查：
- 预扣税：**模式 A 和 B 都要提醒**——付租金的一方（租客或管理者）可能要预扣，业主要把 W-8ECI 等表格给付款方，先问会计（`references/ca-law-checklist.md` §14）
- 维修付款：业主在国外、时差大 → 建议设**备用金**（reserve）或允许管理者在上限内先付（模式 C 或信托），避免急修付不了款
- 押金：建议放在美国账户或信托账户，确保 21 天能按时退
- 接收法律文件的人：写管理者或美国代理人（§1962）

## 第 2 步：输出（先在聊天里出草稿）

1. **检查表**：条款 · 合同里怎么写的 · 风险（高 / 中 / 低）· 建议怎么改
2. **修改建议**：模糊或对一方明显不利的条款，给修改方向（不是法律文本）
3. **给业主的条款解释**：白话说明每个重要条款对业主意味着什么（按 M00 的语言；发送消息模板 `templates/T-owner-messages.md` 第 2 段）
4. **业主常见疑虑和回答思路**：

| 业主担心 | 回答思路 |
|---|---|
| 管理费太贵 | 一个月空置 + 选错一次租客 + 合规风险的成本，对比管理费 |
| 能不能随时解约 | 按合同的终止条款说明；指出已签租约不受影响 |
| 会不会选到坏租客 | 书面标准 + 核实流程（M07），最后由业主决定 |
| 维修会不会乱花钱 | 审批上限 + 报价比较 + 修前修后照片 |
| 租金什么时候到账 | 按付款模式 A / B 说明 |
| 押金放在哪 | 按合同：业主或信托账户 |
| 出了问题谁负责 | 保险 + 合同的责任条款 |
| 能不能涨租、能不能让租客走 | 按 AB 1482 和本地规定说明，驱逐交给律师 |

5. **签约**：电子签 → 用 `references/disclosures-forms.md` 第 3 段做**签齐检查**（这是进入 M03 的关卡）→ 存到 `01-合同租约/`

更新总控台：物业总览（状态 = 签约中 / 接房，以及租金流向、维修付款方式、审批上限）、账单（如果签约时收费）。
