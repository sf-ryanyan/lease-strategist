# X2 — 沟通教练：怎么跟业主、租客、看房人、师傅说

**用量**：🟢 · **触发**：用户贴一段聊天、邮件或截图，问「怎么回 / 怎么说」。

**第 0 步数据**：完整对话（谁、说了什么、什么时候）· 是哪个物业、在哪一步。

## 1. 读懂
- 对方是谁：业主线索 / 签约业主 / 租客 / 看房人或申请人 / 师傅 / 邻居或 HOA
- 在哪一步、对方情绪、**真正想要什么**、风险（法律、公平住房、宜居、钱）

## 2. 选打法

**业主常见要求 → 正确回应**

| 业主说 | 怎么回（思路） |
|---|---|
| 想收 2 个月押金 | 按现行押金上限说明（X3 核实），超收有赔偿风险；可以通过筛选标准控制风险 |
| 不想租给用 Section 8 / 住房券的人 | 收入来源在加州受保护，拒绝有歧视风险；收入只按租客自付部分算，标准和其他人一样 |
| 不想要宠物 / 服务动物 | 可以不收宠物，但服务动物和情感支持动物不是宠物，不能收宠物费，按合理便利流程处理 |
| 想涨很多租金 | 先查是否适用 AB 1482 或本地租控，给出上限和通知期；超限的涨租无效 |
| 想直接去房子看看 | 必须提前书面通知（一般 24 小时），说明原因和时间；紧急情况除外 |
| 不想修 | 业主有宜居维修义务；不修可能导致投诉、租客自行修理后扣租或更大损失 |
| 想把租客赶走 / 换锁 | 自行驱逐违法；必须走正式通知和法院程序 → M16，找律师 |
| 不想做披露 | 披露是法律要求，不做可能导致合同可撤销、被告 |
| 管理费太贵 | 用一个月空置的成本 + 一次选错租客的损失 + 合规风险，对比管理费 |
| 我自己管就行 | 保持友好，给一份免费检查清单，留下以后合作的机会 |
| 我觉得能租更高 | 给成交的对比房源，说明「高位价」的代价（空置更久） |

**租客**
- 报修：先按 M11 分级（紧急的立刻处理）
- 迟交：友好提醒 → 书面通知 → 按 M12 / M16
- 续约：只在上限和通知期以内谈（M14）
- 投诉邻居 / 噪音：记录 → 按 M13 违约阶梯

**看房人 / 申请人**：只按书面标准回答；敏感问题见 `templates/T-inquiries.md` 第 4 段。

**师傅**：讲清楚范围、时间、怎么进门、付款方式、要照片。

## 3. 写
写出可以直接发的下一条消息（短信 / 微信 / 邮件 / Zillow 消息），按对方使用的语言。

## 4. 预测
列出对方 2–3 种可能的回复，以及每种怎么接。

## 5. 解释
用 1–2 句话说明为什么这样回，帮助用户学会套路。

## 绝对不能
威胁、换锁、断水电、报复、评论受保护特征、承诺法律结果、承诺租金或出租天数。用户确认发出后，把消息追加到 `记录.md`。
