# M15 — 退租 + 退房检查 + 押金扣款

**用量**：🔴 完整 · **触发**：租客要搬走、发终止通知、到期不续、退房检查、扣押金、押金明细。

**原则：每一笔扣款都要合理、合法、有证据。万一被告，证据就是保护。**

## 第 0 步：数据

用户已经给了扣款项目 → **直接出草稿**，缺的标「未知」，结尾最多问 2 个最关键的。什么都没给 → 按 SKILL.md 第 5 节只发下面的清单。

| 数据 | 为什么要 |
|---|---|
| **物业地址和城市**（不是租客的新地址） | 部分城市要求付押金利息（比如 San Francisco、Berkeley 等），要按城市核实 |
| 搬出（交回钥匙）日期 | 算 21 天期限 |
| 押金金额、在谁手里、**月租金、押金收取日期** | 业主 / 信托；顺便检查当初收的押金有没有超过上限（AB 12，2024-07-01 起一般一个月） |
| 入住检查报告和照片 | 对比用 |
| 退房检查结果和照片（修前 / 修后） | AB 2801 |
| 每个扣款项目：发票还是报价、**师傅的名称地址电话** | §1950.5 |
| 要换的东西**用了几年**（地毯、油漆、家电） | 折旧 |
| 有没有书面告知租客可以要求退房前检查 | 合规 |
| 欠租、钥匙签收单 | 其他扣款 |

## 第 1 步：触发和确认

- 收到租客的退租通知 / 业主终止（要符合 just cause 等规定，有争议找律师）/ 到期不续
- 检查通知是否有效：月租的租客一般提前 30 天；定期租约看条款
- 书面确认**搬出日期**（`templates/T-tenant-notices.md` 第 14 段）
- 双方协商提前结束 → 签**终止协议**（termination agreement），写明日期、钥匙、押金处理
- 书面告知租客**有权要求退房前检查**（必须告知）
- 更新总控台：租约表的「搬出日」（押金退还截止会自动算出来）

## 第 2 步：退房前检查（租客要求时）

- 在搬出前约 2 周内做；提前 48 小时书面通知（C.A.R. FEHN）
- 对照入住检查报告看一遍，给租客一份**拟扣款项目清单**，让他有机会在搬出前自己修好或清洁

## 第 3 步：给租客的退房指引（`templates/T-tenant-notices.md` 第 15 段）

清洁标准（恢复到入住时的状态，正常损耗除外）· 还所有钥匙、遥控、门禁卡 · 留**新地址**（寄押金明细用）· 停水电或转回业主 · 搬空所有个人物品 · 约退房检查时间。

## 第 4 步：退房检查

1. 用**退房检查清单**（C.A.R. MIMO 的退房栏，或用户的表格）逐个房间检查，对照入住报告和照片
2. 拍照：**收房后、维修清洁前**拍一次；修完再拍一次（AB 2801）
3. 抄水电表
4. **钥匙核对**：收回的钥匙、遥控、门禁卡，和入住时的钥匙签收单逐项对比；少了的记下来（按租约扣费，要有价格凭证）
5. 检查清单由管理者（或业主）签字；租客在场的也请签字

## 第 5 步：判断能不能扣

| 正常损耗（不能扣） | 损坏（可以扣） |
|---|---|
| 正常使用造成的墙面轻微磨损、少量钉孔 | 大洞、涂鸦、未经同意的油漆 |
| 地毯正常磨旧 | 烧痕、宠物尿渍、撕裂 |
| 正常日晒褪色 | 损坏的门、窗、纱窗、柜子 |
| 老化的家电零件 | 使用不当造成的损坏 |
| 正常的灰尘 | 留下大量垃圾、需要深度清洁（超出入住时的状态） |

**折旧（很重要）**：地毯、油漆、地板、家电等有使用年限。损坏需要更换时，只能扣**剩余使用年限对应的部分**，不能按全新价全扣；已经超过使用年限的，通常不能扣。
- 算法：更换费用 × 剩余年限 ÷ 使用年限（使用年限参考：地毯常按 5–10 年、室内油漆常按 3–5 年估计，标 [假设]，有争议以实际情况和律师意见为准）
- 不知道用了几年 → 先问用户；仍未知就标「未知，可能需要折旧」，并提示风险
- 使用年限是假设的区间时，**主表用扣得最少的那个金额**，后面写区间和理由

## 第 6 步：扣款证据（每一项都要有）

| 项目 | 金额 | 折旧计算 | 照片（前 / 后） | 发票 / 估价 | 师傅名称、地址、电话 | 法律依据（租约条款 / §1950.5） |
|---|---|---|---|---|---|---|

- 能扣的：欠租、清洁到入住时的状态、超过正常损耗的损坏（按折旧）、租约允许的其他费用
- 维修加清洁合计超过 USD 125 → 附发票或收据；业主或员工自己做的写工时和时薪
- 发票上没有师傅的名称、地址、电话 → 写在明细里
- **能在 21 天内修完的先修完再寄**；只有**确实来不及**在 21 天内修完时，才用合理估价（写明是估价和师傅信息），修完后 14 天内补发票

**常见补救**
- 没有书面告知租客可以要求退房前检查 → 照样按时寄明细，但在给用户的提示里写明风险（租客可能质疑扣款）
- 已经修了但**没有修前照片** → 用入住报告、退房检查清单、师傅的书面说明作为证据；证据弱的项目建议少扣或不扣
- 证据不足的项目，宁可不扣，降低被告风险

## 第 7 步：21 天内寄出

- **从搬出（交回钥匙）那天算 21 天**，写出具体截止日期（YYYY-MM-DD + 星期几）。总控台每次打开都提醒剩几天
- 寄出**逐项扣款明细** + 发票收据 + **修前修后照片**（AB 2801）+ 退款（按约定方式；AB 414 起可以按约定用电子方式）。保留寄出凭证
- 部分城市要付押金利息 → 按城市核实后加进去
- 押金在业主手里 → 提醒业主按时退（给业主一个比截止日早几天的日期）；在信托账户 → 从信托退
- 模板：`templates/T-tenant-notices.md` 第 16 段

## 第 8 步：租客留下的物品

不能马上丢。按法定程序书面通知（`references/ca-law-checklist.md` §11）。

## 第 9 步：收尾，形成闭环

- 换锁芯或改电子锁密码；水电转回业主名下
- 给业主一份**退租报告**：退房检查结果、扣款明细、退款金额、房子现状、建议修缮项目和费用
- 下一步：回到 **M04**（接房评估和修缮）→ **M05**（重新上市）

## 输出

短版：截止日期和剩几天 → 扣款明细表（含折旧和证据状态）→ 退款金额 → 风险 → 下一步。完整版再加：搬出确认、退房前检查通知、退房指引、退房检查清单、押金明细（英文）、退租报告。更新总控台：物业总览（状态 = 退租中 → 修缮）、租约表的搬出日。
