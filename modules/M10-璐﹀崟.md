# M10 — 账单：管理费 invoice、月度对账单、年度汇总

**用量**：🟢 轻量 · **触发**：invoice、账单、管理费、租赁费、续约费、对账单、月报、年报。

## 第 1 步：先确认

- 这个物业的托管合同怎么约定收费（按 M02 / M00）：租赁费、月管理费、续约费、维修协调费、其他
- **付款模式**：A（租客直付业主）/ B（代收 → 信托账户）

## 模式 A：给业主开 invoice

**Invoice 字段**：
- 账单号（例：INV-2026-001）、开票日期、到期日
- 开票方：品牌、broker、联系方式（M00）
- 收票方：业主姓名、地址
- 物业地址
- 明细：项目 · 期间 · 计算方式（例如「月租 USD X × Y%」或固定金额）· 金额
- 合计、付款方式（由管理者填写账户信息，skill 不保存）、付款条款（比如 15 天内）

总控台「账单」表记录，到期未付 → 提醒，发催款消息（`templates/T-业主沟通.md` 第 6 段）。

## 模式 B：月度对账单（从收到的租金里扣费）

| 项目 | 金额 |
|---|---|
| 本月收到租金 |  |
| + 其他收入（滞纳金等，按合同归属） |  |
| − 管理费 |  |
| − 维修和其他支出（附发票） |  |
| − 留存的备用金（reserve） |  |
| **= 实付业主** |  |
| 付款日期 |  |

附：维修发票清单、租金记录。提醒信托账户的记账和对账要求（`references/加州法规清单.md` §13），每月对账、不能混用。

## 年度汇总（每年 1 月，两种模式都做）

- 全年租金收入（按月）
- 全年费用：管理费、维修（按类别）、其他
- 空置天数、租客变动
- 押金状态
- 提醒：1099 等税表的事问会计；海外业主的预扣税问会计（§14）

## 输出

Invoice 或对账单（先在聊天里出草稿，确认后生成 Excel 或 PDF）· 年度汇总。更新总控台：账单表。
