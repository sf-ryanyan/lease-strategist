# M00 — 首次设置（只做一次，之后可随时修改）

**用量**：🟡 · **触发**：用户说「设置 / 改设置 / 我的资料」；或第一次使用、没有具体任务（规则见 SKILL.md 第 2 节——**带着具体任务来的，先做任务，不要先发问卷**）。

## 做法

一次发出下面的问卷（可以只填一部分；问卷不受「一次 1–2 个问题」的限制）。用户回复后，整理成「设置卡片」：
- 有文件夹 → 存为 `租管数据/设置.md`，并在总控台「使用说明」页填好
- 没有文件夹 → 在聊天里给出设置卡片，请用户保存，下次粘贴

用户说「先跳过」或只填了一部分 → **照样存卡片**，没填的用下面的默认值或写「未设置」。以后不再整体重问，用到哪项再单独问哪项。

## 默认值（没填时用）

| 项目 | 默认 |
|---|---|
| 品牌、broker、DRE、联系方式 | 未设置（对外材料里留占位并提醒补） |
| 默认服务类型 | 全托管 |
| 收费 | 按房报价 |
| 租金流向 | 未设置（用到时问） |
| 维修付款 | 业主直付 |
| 押金保管 | 业主 |
| 审批上限 | 无（每次都先问业主） |
| 语言 | 业主：中文 · 租客：英文 |
| 招租标准 | 未设置（第一次上市时在 M04 第 7 步和业主一起定） |
| 提醒 | 只在打开时提示；天数见第 18 项 |

## 问卷

**A. 管理者资料**（出现在业主材料和房源广告上）
1. 姓名 / 品牌名
2. 负责的 broker 名称
3. DRE 号（个人 + broker）。加州规定持牌人的首次接触营销材料要写 DRE 号，按 DRE 登记的名字写。不知道就留空，用到时再提醒，**绝不编造**
4. 对外联系方式（电话、邮箱、网站）

**B. 业务**
5. 服务区域（城市 / 县）
6. 主要物业类型：独立屋 / 公寓（condo）/ 联排 / 小型多户 / ADU
7. 默认服务类型：**只招租**（Leasing only，做到 M09 结束）/ **全托管**（Full management）。每个物业可以单独改

**C. 钱**
8. 收费方式（每项可选：百分比 / 固定金额 / 按房报价 / 不收）：
   - 租赁费（签约时收一次）
   - 月管理费
   - 续约费
   - 维修协调费或加价
   - 其他（上门费、空置期费用等）
9. **租金流向（付款模式）**：
   - **A**：租客直接付给业主，管理者给业主开 invoice
   - **B**：管理者代收 → 存入信托账户（trust account）→ 扣费后打给业主
   - 选 B 时提醒：加州持牌人代收客户资金要按 DRE 规定使用信托账户、记账和对账，并由 broker 监管。不确定就先问 broker
10. 维修费默认怎么付：业主直接付 / 从信托账户付 / 租客先付再报销（**C**）
11. 押金由谁保管：业主 / 信托账户
12. 默认维修审批上限：USD ____ 以下可直接派工（没有就填「无」，每个物业可以单独改）

**D. 偏好**
13. 给业主的语言：中文 / 英文 / 按业主定
14. 给租客的语言：英文 / 中英双语
15. 默认上市平台：MLS / Zillow / Craigslist / Facebook / Apartments.com / 自己的网站
16. 常用工具（只记名称）：申请筛选平台、电子签、记账软件
17. 主动提醒：只在打开 skill 时提示（默认）/ 另外设每周自动检查（见 X1 的「可选：每周定时检查」）
18. 提醒天数（不填就用默认）：交租前提醒（默认 3 天）· 上市调价检查（默认第 7 / 14 / 21 天，上市当天算第 0 天）· 入住后租客补充问题的期限（默认 7 天）· 续约启动（默认到期前 90 / 60 / 30 天）

**E. 默认招租标准**（每个物业上市前可以改，M04 第 7 步、M07 第 1 步用）
19. 收入要求：月收入为租金的几倍（或同等付款能力证明）
20. 申请费：USD ____ / 每位成年申请人（不超过当年法定上限）
21. 宠物政策：不接受 / 个案考虑 / 接受（宠物押金和其他押金合计不超过上限；服务动物不是宠物）
22. **选择方式**（AB 2493 二选一）：先到先得（第一位符合标准的完整申请）/ 比较多份申请后由业主选（没有处理的申请要退申请费）

```
联系：{电话 / 邮箱 / 网站}
区域：{…} · 物业类型：{…} · 默认服务：{只招租 / 全托管}
收费：租赁费 {…} · 月管理费 {…} · 续约费 {…} · 维修协调 {…} · 其他 {…}
租金流向：{A / B} · 维修付款：{业主直付 / 信托 / C 租客垫付} · 押金保管：{业主 / 信托}
审批上限：{USD … / 无}
语言：业主 {…} · 租客 {…}
平台：{…} · 工具：{…} · 提醒：{打开时 / 每周}
提醒天数：交租前 {3} 天 · 调价 {7/14/21} · 入住补充 {7} 天 · 续约 {90/60/30}
招租标准：收入 {X} 倍 · 申请费 USD {…} · 宠物 {…} · 选择方式 {先到先得 / 比较后选}
```
