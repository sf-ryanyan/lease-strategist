# M04 — 接房评估 + 修缮 + 上市时间线

**用量**：🟡 标准 · **触发**：房况、检查、要修什么、清洁、找师傅报价、时间线、什么时候能上市。

## 第 0 步：数据

各个房间和外部的照片或视频 · 建造年份 · 已知问题 · 设备清单 · 业主的预算和期望上市日期 · 有没有审批上限。

## 第 1 步：管理者检查清单

**每个房间**：墙面、地板、门窗和锁、灯和开关、插座、窗帘或百叶、气味、清洁程度。评级：好 / 一般 / 要处理。

**系统**：屋顶、排水沟、HVAC（暖气 / 空调、滤网）、热水器（是否**绑带固定**）、电路面板、水管（有无漏水、水压）、下水道、车库门。

**家电清单**：

| 家电 | 品牌 / 型号 | 使用年限 | 能用吗 | 备注 |
|---|---|---|---|---|
| 炉灶 / 烤箱（2026 起必须提供） |  |  |  |  |
| 冰箱（2026 起必须提供，租客自带的要写进租约） |  |  |  |  |
| 洗碗机、微波炉、洗衣机、烘干机、垃圾处理器 |  |  |  |  |

**安全合规**：
- 烟雾报警器：每间卧室 + 卧室外走廊 + 每层，测试过
- 一氧化碳报警器：有燃气设备或附属车库的
- 热水器绑带固定
- 门闩锁和窗锁能用
- 有没有漏水、霉菌、虫害的迹象，有没有绊倒风险
- 1978 年前的房子：动油漆时按含铅安全规范施工

**卫生评级**：可以直接上市 / 普通清洁 / 深度清洁。

**接房照片**：每个房间都拍，带时间戳，存到 `04-照片/接房-{日期}/`。退押金时要用来对比。

## 第 2 步：业主知情问卷（业主有义务告知已知情况）

发给业主，请书面回复：
1. 以前漏过水吗？有没有霉菌、虫害（含臭虫）、老鼠？处理过吗？
2. 有没有加建或改建没拿到许可（permit）的部分？
3. 屋顶、热水器、HVAC 大概几年了？最近修过什么？
4. 报过保险理赔吗？
5. 有 HOA 吗？有没有纠纷、出租限制、审批流程？
6. 3 年内有没有人在房内死亡？
7. 附近有没有业主知道的问题（施工、噪音、洪水）？
8. 有没有定期除虫或其他服务合同？
9. 你希望出租时保留哪些家具或家电？

回复里的内容可能要写进 M08 的披露。

## 第 3 步：修缮清单

分三级，每项写参考费用区间（湾区起点价，**以本地报价为准**，标 [假设]）：
- **必修**：安全和宜居相关
- **建议修**：能提高租金或缩短空置
- **可选**

| 项目 | 起点参考价 |
|---|---|
| 全屋内墙刷漆（约 1,500 sqft） | USD 4,500–9,000 |
| 局部补漆 | USD 400–1,200 |
| 退租深度清洁 | USD 350–800 |
| 地毯清洗 | USD 150–350 |
| LVP 地板（含安装） | USD 7–12 / sqft |
| Handyman | USD 90–150 / 小时 |
| 热水器更换 | USD 2,500–4,500 |
| 垃圾处理器 | USD 350–600 |
| 烟雾 / CO 报警器（含安装） | USD 40–90 / 个 |
| 换锁芯 | USD 150–300 |
| 院子清理 | USD 300–1,000 |

**每项建议修的写回报**：花多少 · 预计多租多少（来自 M01 三档价格）· 几个月回本。

## 第 4 步：找师傅报价

1. 写**工作说明（scope of work）**：地址、位置、问题、要做什么、材料要求、照片、怎么进门、希望的完成日期、要修前修后照片 → 模板见 `templates/T-师傅.md`
2. 建议找 2–3 家比价（金额小的可以 1 家）
3. 超过 USD 1,000（人工 + 材料）或需要许可的工程 → 找有 CSLB 执照的承包商，在 cslb.ca.gov 查执照（`references/加州法规清单.md` §10）

## 第 5 步：发业主审批

报价汇总表：项目 · 级别（必修 / 建议 / 可选）· 报价 · 选哪家 · 回报。业主**书面批准**后才开工。消息模板：`templates/T-业主沟通.md` 第 3 段。

## 第 6 步：时间线

顺序：维修 → 清洁 → **拍照日** → 上市日。
- 每项写开始日期、天数、负责人
- 留缓冲：等材料、等 HOA、等许可
- 提醒业主**空置成本**：每空一天大约损失月租的 1/30

把时间线发给业主确认 → 定下上市日期 → 写进总控台待办提醒。

## 第 7 步：上市前准备清单

- [ ] 修缮和清洁完成，修后照片存档
- [ ] 安全设备都测试过
- [ ] **书面筛选标准**写好并经业主同意（从 M00 的默认招租标准开始改，详见 M07 第 1 步），包括**选择方式**（先到先得 / 比较后选）——上市期间不能改
- [ ] 披露文件准备好（`references/披露与表格.md`）
- [ ] 最终租金（参考 M01，必要时重新看一次市场）
- [ ] 看房方式定好（管理者带看 / 密码锁盒自助看房）

## 输出

检查清单结果 · 业主知情问卷 · 修缮清单 + 回报 · 工作说明和询价消息 · 报价汇总（给业主审批）· 时间线 · 上市前准备清单。

更新总控台：物业总览（状态 = 修缮）、待办提醒（每个时间节点）、师傅名单。下一步 → M05。
