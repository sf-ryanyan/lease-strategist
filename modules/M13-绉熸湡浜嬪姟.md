# M13 — 租期内事务：进屋、违约、检查、住户变动、事故、空置、日常通知

**用量**：🟡 标准 · **触发**：进屋通知、违约、噪音、宠物、多住了人、停车、垃圾、加室友、提前解约、转租、合理便利、火灾 / 水淹 / 盗窃、空置、定期检查、给租客发通知、业主来信。

只读需要的那一段。

## §1 进屋通知

- 一般提前 24 小时书面通知；邮寄的提前 6 天；正常工作时间；写明日期、大概时间、原因（§1954）
- 合法原因：必要或约定的维修和服务、带看、退房前检查、法院命令等；紧急情况或租客当场同意时除外。**例行定期检查要租约里有约定或租客同意**（见 §3）
- 模板：`templates/T-租客通知.md` 第 4 段（按原因选）；正式表格 C.A.R. NOE
- 送达方式和时间记进 `06-通知/`

## §2 违约处理阶梯

常见：噪音、未登记的宠物或住户、停车、垃圾、吸烟、私自转租或做 Airbnb、损坏、违反 HOA 规定。

| 级别 | 做什么 | 模板 |
|---|---|---|
| 1. 留证据 | 日期、时间、照片、邻居或 HOA 的书面投诉 | — |
| 2. 友好提醒 | 指出租约条款，请在 X 天内改正 | `T-租客通知.md` 第 10 段 |
| 3. 书面警告 | 写明违反哪一条、要求改正的期限、不改的后果 | `T-租客通知.md` 第 11 段 |
| 4. 正式通知 | 3 天纠正或搬离通知等 → **先找律师或 broker** | M16 |

每一步都记录。HOA 罚款按租约和 HOA 规定处理。

## §3 定期检查

- 先看租约有没有定期检查条款、业主和租客是否同意；按进屋通知规则提前通知
- 建议每半年一次，加季节性保养：秋天清排水沟、换空调滤网、测试烟雾和 CO 报警器、检查热水器和漏水、春天检查草坪和灌溉
- 输出：检查表 + 照片 + 给业主的建议（需要修的 → M11）

## §4 租期内住户变动

| 请求 | 流程 |
|---|---|
| **加室友** | 新住户按同一套标准筛选（M07）→ 业主批准 → 租约附加条款，所有人签字。注意：加了成年住户会影响 AB 1482 just cause 的计算 |
| **减室友** | 业主同意 → 修改租约或附加条款；押金怎么处理要写清楚（一般押金跟着租约，不在中途分） |
| **提前解约** | 看租约有没有提前解约条款；业主有义务合理努力重新出租来减少损失；协商结果写成书面终止协议 → M15 |
| **转租 / 转让** | 按租约；一般需要业主书面同意；新租客要过筛选 |
| **养宠物** | 按宠物政策 → 业主批准 → 附加条款 |
| **合理便利**（服务动物、指定车位、加装扶手等） | 按公平住房的合理便利流程评估 → 书面记录 → 不能因此收费（服务动物） |
| **租客去世** | 先联系紧急联系人；不要自行处理物品；问律师 |

## §5 重大事故：火灾、水淹、入室盗窃、严重漏水

1. 人身安全第一 → 911 / 紧急服务
2. 马上通知业主（`templates/T-业主沟通.md` 第 10 段）；业主通知**房屋保险**；提醒租客通知**租客保险**
3. 拍照和视频，写事故报告：时间、经过、损失、已采取的措施
4. 止损：关水、临时封堵、防盗
5. 判断房子还能不能住；不能住 → 和业主、律师讨论租金减免或临时住宿（看保险和租约）
6. 修复走 M11，按保险公司的要求留证据和发票
7. 被盗 → 报警，拿报案号；换锁芯

## §6 空置期管理

- 提醒业主：房屋空置太久，部分保险可能不保（看保单的空置条款）
- 水电保持最低需要；冬天防冻；草坪和院子定期维护
- 每 1–2 周巡查一次：门窗、漏水、信件、有没有人擅自进入
- 写进待办提醒

## §7 给租客的通知

HOA 通知、计划停水停电、除虫、施工、公共区域维修、规则变更 → `templates/T-租客通知.md` 第 12 段。

## §8 业主来信、来件、业主的请求

- 寄到物业的业主信件或包裹 → 拍照告诉业主，按约定转寄
- 业主想去看房 → 按进屋通知规则
- 业主想改规则（禁宠物、涨租等）→ 先看租约和法规；租期内一般不能单方面改

## §9 合规日历

总控台待办提醒里加：租约到期 90/60/30 天、保险到期、HOA、租控城市年度登记、报警器检查、每年 1 月 1 日新法、8 月 1 日 AB 1482 上限更新（X3）。
