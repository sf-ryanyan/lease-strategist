# M17 — 结束托管 / 租期内卖房 / 换业主 / 海外业主

**用量**：🟡 标准 · **触发**：业主不托管了、解约、卖房、过户、换业主、海外业主、预扣税。

## §1 业主结束托管（或管理者结束服务）

1. 按托管合同的终止条款：通知天数、终止费、生效日期
2. **交接清单**：
   - [ ] 所有文件：租约、披露、附加条款、检查报告、照片、通知、维修记录、保险
   - [ ] 钥匙、遥控、门禁卡（签交接单）；电子锁和各种 App 的权限转移
   - [ ] **押金**：在信托账户的 → 按规定转给业主或新管理者，并书面通知租客押金现在在谁手里
   - [ ] 信托账户里的其他钱：最终对账单 → 结清（模式 B）
   - [ ] 未结的维修工单、未付的账单、待办事项
   - [ ] 师傅名单和保修信息（如果业主需要）
3. **通知租客**：从哪天起管理者变了、以后联系谁、交租方式（§1962）
4. 给业主一份最终报告和最终 invoice（M10）
5. 更新总控台：物业状态 = 已结束；保留记录至少 3 年

## §2 租期内卖房

- **租约继续有效**：新业主接手现有租约
- **带看**：按进屋规则提前书面通知（可用 C.A.R. NSE 出售和进屋通知），合理时间，尊重租客
- **押金**：卖房时押金要转给新业主并书面通知租客（含金额和扣款情况），或者按规定退给租客
- 业主想空房出售 → 是否可以终止租约要看 just cause 和本地规定 → 找律师
- 新业主还想继续托管 → 回到 M02 签新的托管合同

## §3 海外业主（只提醒，不是税务建议）

- 签托管合同前就提醒：**两种模式都要注意**——模式 B 是管理者付租金给业主，模式 A 是租客直接付，**付款方**都可能要做联邦和加州的预扣税（W-8ECI 等表格、FTB Form 592 相关）
- 维修付款和押金：见 M02「海外业主另外检查」
- 让业主问会计，确定用哪些表格、谁负责预扣和申报
- 联系方式要有业主在美国的授权联系人（紧急时能决定维修）
- 时差：在托管合同里写明紧急维修的授权（M02 第 6 项）

## 输出

交接清单 · 给租客的通知（`templates/T-tenant-notices.md` 第 17 段）· 最终报告 · 卖房期间的带看通知安排。
