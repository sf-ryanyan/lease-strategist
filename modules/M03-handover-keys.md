# M03 — 交接确认 + 钥匙

**用量**：🟡 标准 · **触发**：接房、交接、拿钥匙、钥匙清单、现有租客、水电账户。

## 第 0 步：数据

签好的托管合同 · 可交接日期 · 房子现在的状态（空置 / 有租客 / 业主刚搬走）· 业主手上的钥匙和设备清单 · 水电账户信息（只记公司名称和账户在谁名下）。

## 第 1 步：关卡 — 合同签齐了吗

用 `references/disclosures-forms.md` 第 3 段检查托管合同。有缺的 → 列出来，**补齐前不进行交接**。

## 第 2 步：现有租客 — 只提醒，不直接上手

- 新管理者没有和旧租约的签约方签过约，旧租约里的事**原则上不参与**。
- skill 只做两件事：
  1. **提醒管理者要谨慎**：不要自己去收旧押金、不要发通知、不要答应旧租客任何事，除非托管合同明确授权
  2. **给业主一份处理指引**：业主自己书面通知租客「从哪天起由谁管理、以后怎么交租、联系谁」（§1962 告知义务）；押金交接是业主的责任，要书面记录金额和去向；收集旧租约副本、当前租金、到期日、交租记录、未解决的问题
- 只有托管合同**明确写了**、业主**书面授权**之后，管理者才介入。介入后，「新管理者 15 天内书面告知租客」的义务（§1962，见 `references/ca-law-checklist.md` §9）也由管理者负责。

**缺失和风险**
- 不知道还有谁拿着钥匙（前租客、工人、亲友）→ 建议换锁芯（rekey），新租客入住前换是常规做法
- 电子锁：改主密码、删除旧用户；车库遥控：重新配对
- HOA 门禁卡或遥控要找 HOA 申请，可能要几周，**现在就开始办**
- 室内门有锁没钥匙 → 配钥匙或换成无锁把手
- 主入口门要有能用的门闩锁（deadbolt），窗户要能锁（§1941.3）

## 第 4 步：水电煤网

- 每项：公司名称（参考 `references/bay-area-cities.md` 第 2 段）· 账户在谁名下 · 交接当天抄表（拍照）
- 空置期间谁付（一般是业主）；哪些以后转到租客名下，哪些按租约由业主付

## 第 5 步：钥匙签收单（业主 → 管理者）

写明：日期 · 物业地址 · 每项钥匙和设备的数量 · 双方签名 · 拍照存档到 `04-照片/`。

## 输出

关卡结果 · 现有租客的提醒和业主指引（如果有）· 钥匙清单表 + 缺失风险和建议（含大概费用，标 [假设]）· 水电清单 · 钥匙签收单草稿。

更新总控台：物业总览（状态 = 接房）、待办提醒（换锁芯、HOA 门禁卡等）。下一步 → M04。
