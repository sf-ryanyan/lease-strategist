# M11 — 维修工单：从报修到付款归档

**用量**：建单和分级 🟢 / 定责任、报价和审批 🟡 · **触发**：报修、坏了、漏水、没热水、维修、师傅、报价、工单状态。

## 🔴 紧急情况先处理（不用等任何步骤）

| 情况 | 马上做 |
|---|---|
| 闻到燃气味 | 让所有人**立刻离开**房子，出门时可以把门开着；**不要**开关灯和电器、不要点火或用打火机、不要在屋里或附属车库里打电话、不要发动车库里的车。到外面安全的地方打 **911** 或燃气公司 24 小时紧急电话（多数是 PG&E）。燃气公司关气后，**不要自己重新开**，等他们或持证师傅处理。给租客的英文消息：`templates/T-tenant-notices.md` 第 18 段 |
| 火灾、CO 报警器响 | 911；离开房子 |
| 水管爆裂、大量漏水 | 让租客关总水阀（告诉他在哪），再派紧急水管工 |
| 污水倒灌 | 停止用水，派紧急疏通 |
| 全屋没电、电线冒烟或火花 | 有危险 → 911；否则电力公司 + 电工 |
| 外门锁坏、门窗破、无法锁门 | 锁匠，当天处理 |
| 冬天没暖气、完全没水 | 当天联系师傅 |

紧急情况：先处理、马上通知业主，按托管合同的紧急授权条款执行；事后补齐记录和照片。

## 第 1 步：建工单（问清楚）

**请租客提供**（模板 `templates/T-tenant-notices.md` 第 5 段）：什么问题 · 在哪个位置 · 从什么时候开始 · 是持续还是偶尔 · 照片或视频 · 设备品牌和型号（铭牌照片）· 方便上门的时间 · 家里有没有宠物 · 可不可以在不在家时进门。

**按问题类型追问**：
- 漏水：在哪里漏？现在还在漏吗？有没有关水阀？天花板或地板有没有湿？
- 没热水：燃气还是电？指示灯亮吗？漏水吗？
- 空调或暖气：恒温器显示什么？滤网多久没换？
- 下水道或马桶：一个地方还是多个地方？有没有倒灌？
- 家电：型号？显示什么错误代码？

**先让租客做的安全排查**（能省一趟师傅）：重置跳闸开关 · 重置浴室或厨房的 GFCI 插座 · 垃圾处理器底部复位按钮 · 用皮搋子疏通马桶 · 更换恒温器电池 · 检查是否欠费停电或停气。

## 第 2 步：分级

| 级别 | 例子 | 响应 |
|---|---|---|
| 🔴 紧急 | 上面的紧急表 | 立即 |
| 🟠 优先 | 没热水（宜居项目，尽快）、水槽或管道下方持续漏水（关了阀才停）、马桶堵（只有一个马桶时更急）、屋顶漏水、冰箱或炉灶坏（AB 628：收到书面通知后 30 天内修好或换新）、虫害、跳闸反复 | 3 天内（总控台「应完成日」= 报修日 + 3） |
| 🟢 常规 | 水龙头滴水、关阀就能控制的小滴漏、马桶一直流水、瓷砖坏、车库门问题、柜门松动 | 14 天内（应完成日 = 报修日 + 14） |

紧急的应完成日 = 报修当天。

影响宜居的问题（§1941.1）要优先，并记录处理时间。

## 第 3 步：判断责任（每张工单都要定性）

- **房屋本身的问题**（正常老化、设备故障）→ 业主承担
- **租客造成的**（使用不当、损坏、堵塞物）→ 按租约由租客承担
- **责任分工表**里写明由租客负责的项目（如滤网、灯泡、报警器电池）→ 提醒租客自己处理
- 不确定 → 让师傅或检查员在报告里**写明原因**（加照片），作为定责任的证据。定责任前不要先跟租客说「你来付」

## 第 4 步：审批逻辑

```
这个物业有审批上限吗？（总控台「物业总览」；没填 → 用 M00 设置的默认值）
├─ 有
│   ├─ 预计费用低于上限 → 直接派工，事后告诉业主
│   └─ 高于上限 → 报价 → 业主书面批准 → 派工
└─ 没有
    └─ 先请师傅上门诊断（上门费先告诉业主并得到同意）
        → 报价 → 业主书面批准 → 维修
```

- 报价：预计超过 USD 1,000 或需要许可的，找 2–3 家比较，并且必须是有 CSLB 执照的承包商；影响宜居的（比如没热水）**报价和请业主批准同时进行**，不要排队等
- 需要许可、动到热水器、燃气或电路、或者是 1978 年前的房子 → 读 `references/ca-law-checklist.md` §7、§10（绑带固定、CO 报警器、许可和验收、含铅安全施工）
- **追加费用**：施工中发现要加钱 → 停下，业主再批准一次

## 第 5 步：给师傅的说明（模板 `templates/T-vendors.md`）

问题描述 · 照片和视频 · 设备品牌和型号 · 具体位置 · 怎么进门（租客在家 / 密码锁盒 / 管理者开门）· 宠物 · 约好的时间 · 预算或上限 · **要求修前修后照片和书面发票** · 付款方式。
目的是让师傅**一次带齐工具和配件**。

从总控台「师傅名单」按工种推荐；没有合适的 → 建议用户找 2–3 家本地有评价、有执照和保险的。

## 第 6 步：约时间

- 和租客、师傅两边确认时间
- 租客不在家或需要进门 → 提前书面进屋通知（一般 24 小时，`templates/T-tenant-notices.md` 第 4 段）；紧急情况或租客当场同意时除外

## 第 7 步：完成确认

- 师傅提供修前修后照片、书面发票（写明原因和工作内容）
- 租客确认修好了（模板 `templates/T-tenant-notices.md` 第 6 段）
- 需要的话管理者上门验收

## 第 8 步：付款

按这个物业的**维修付款方式**（总控台物业总览；没填用 M00 默认）：
- **业主直付**：业主直接付给师傅（把发票转给业主）
- **信托**：从信托账户或备用金付，记入月度对账单
- **C 租客垫付**：租客先垫付 → 提交发票 → 业主或管理者报销（按租约和业主批准）
- 业主在国外、联系不上又急需付款 → 按托管合同的备用金或紧急授权条款处理
- 租客造成的损坏：按租约向租客收费，附发票和照片

## 第 9 步：归档

工单、照片、发票存到 `05-维修/`。总控台「维修工单」表更新状态：报修 → 已分级 → 报价中 → 待批准 → 已派工 → 已完成 → 已付款 → 已归档。好的师傅加进「师傅名单」。

**禁止**：因为租客报修而报复（涨租、减少服务、终止租约）。
