# 模板：给师傅（英文）

> 只读需要的那一段。不要把租客的敏感信息发给师傅，只给进门和联系需要的信息。

## 第 1 段 · 工作说明 + 询价（scope of work）

```
Quote request – {Address} ({City})

Issue: {clear description}
Location: {room / area}
Since: {when} · {constant / intermittent}
Equipment: {brand, model, age – photo of label attached}
Photos/video: {attached}
Work requested: {diagnose and repair / replace / clean / paint …}
Materials: {any requirements}
Access: {tenant home / lockbox / manager meets you} · Pets: {yes/no}
Preferred date: {…} · Needs permit? {yes/no/unknown}

Please send: a written quote (labor + materials), earliest available date, your CSLB license # (for jobs over USD 1,000 or needing a permit) and proof of insurance.
After the job: before/after photos and an itemized invoice that states the cause of the problem.
```

## 第 2 段 · 派工确认

```
Approved – {Address}
Job: {…} · Approved amount: up to USD {…} (please call before going over)
Appointment: {Date, Time window} · Tenant contact for access: {first name, phone}
Entry: {instructions}
Payment: {owner pays directly / paid by manager from trust / tenant pays and is reimbursed} – invoice to {who}.
Please send before/after photos and the invoice when done.
```

## 第 3 段 · 紧急派工

```
URGENT – {Address}
{Issue: e.g., active water leak under kitchen sink; main shut-off has been turned off}
Please call {Manager} at {Phone} right away with your ETA.
Access: {…} · Authorized for emergency work up to USD {…}.
```

## 第 4 段 · 完成后要资料

```
Hi {Vendor}, thanks for completing the work at {Address}. Could you please send:
1. Before/after photos
2. Itemized invoice (labor, materials, date)
3. Cause of the problem (e.g., normal wear / tenant-caused / unknown)
4. Any warranty on the work
```
