# 法定披露清单 + C.A.R. 表格代码

> 整理日期：2026-10-24。⚠️ 披露清单每次签约前核实（C.A.R. 每年更新 Lease/Rental Disclosure Chart，可以对照最新版）。
> 本 skill 只写表格代码和用途，不复制表格原文。用户用 zipForm 或正式表格填写。

## 第 1 段 · 法定披露

**所有时间要求**：签约**之前**提供，建议提前 2–3 天发给租客；双方签字；给租客副本；记录发送日期和方式；至少保存 3 年。**签完再补不算数。**

### A. 基本都要（按条件确认）

| 披露 | 什么时候要 | C.A.R. 表格 / 来源 |
|---|---|---|
| 含铅油漆 + EPA 手册 | 1978 年前建的房子（联邦要求） | LPD |
| 臭虫（bed bug） | 所有住宅租约 | BBD |
| 涨租上限和 just cause 通知（AB 1482） | 适用或豁免都要处理（豁免要写豁免声明） | RLMM 里的条款 / RJC 等 |
| 洪水风险 | 按规定的洪水区披露 | TFHD |
| Megan's Law（性犯罪者数据库） | 所有租约，写明可查 meganslaw.ca.gov | 租约条款 |
| 霉菌手册（加州 DPH） | 所有租约 | DPH 手册 |
| 除虫服务 | 有定期除虫合同或处理记录时 | 除虫报告副本 |
| 烟雾 / CO 报警器 | 确认已安装并告知 | 租约条款 |
| 炉灶和冰箱（AB 628） | 2026 起；租客自带冰箱时要写明 | 租约条款 ⚠️ 核实最新表格 |
| 管理者 / 业主 / 送达代理人 / 交租方式（§1962） | 写在租约里；签约后 15 天内给租客签好的副本；接手的新管理者 15 天内告知 | 租约条款 |

### B. 有条件时才要

| 披露 | 什么条件 |
|---|---|
| HOA 规定、CC&Rs | 有 HOA 的物业；出租需要 HOA 审批时先办 |
| 3 年内有人在房内死亡 | 所有住宅租约都要考虑（HIV/AIDS 相关的不用披露） |
| 冰毒实验室清理 | 有相关记录时 |
| 前军事弹药区 | 业主知道在附近 1 英里内时 |
| 共用水电表 | 有共用表或分摊收费时 |
| 分户水表 | 分户计量收水费时 |
| 拆除计划 | 已申请拆除许可时 |
| 违约报告信用机构 | 业主会把迟交报给信用机构时（15 户以上有额外要求） |
| 禁烟区域 | 有禁烟政策时 |
| 业主已知的房屋缺陷 | 业主知情问卷（M04）里提到的 |
| 租约译本（§1632） | 租期超过一个月、主要用中文 / 西语 / 他加禄语 / 越南语 / 韩语谈的 → 签约前给该语言的译本 |

## 第 2 段 · 常用 C.A.R. 表格代码

| 代码 | 名称 | 用在哪一步 |
|---|---|---|
| PMA | 物业管理合同 Property Management Agreement | M02 |
| LL | 出租挂牌合同 Lease Listing Agreement（只招租） | M02 |
| LRA | 租房申请 Application to Lease or Rent | M07 |
| BIRN | 背景调查通知 | M07 |
| RLMM | 住宅租约或月租合约 Residential Lease or Month-to-Month Rental Agreement | M08 |
| LPD / BBD / TFHD | 含铅 / 臭虫 / 洪水披露 | M08 |
| PPN | 入住前付款通知（入住款没付清） | M09 |
| MIMO | 入住 / 退房检查表 | M09、M15 |
| NOE | 进屋通知 Notice of Entry | M13 |
| NSE | 出售和进屋通知 Notice of Sale and Entry | M17 |
| CTN | 租约条款变更通知 Notice of Change in Terms（涨租等） | M14 |
| NTT | 终止租约通知 Notice of Termination of Tenancy | M14、M15 |
| FEHN | 退房前检查 48 小时通知 | M15 |
| NTQ | 搬离通知 Notice to Quit | M16 |
| NPC | 要求用现金 / 汇票 / 本票付款的通知 | M12 |
| 3 天付租或搬离通知 | Notice to Pay Rent or Quit | M16 |

⚠️ 表格名称和版本会更新，以用户 zipForm 里的最新版为准。不确定用哪张 → 问 broker 或 C.A.R. 法律热线。

## 第 3 段 · 文件签齐检查（M02、M08、M14 通用）

- [ ] 每一页都在（看页码 X of Y）
- [ ] 所有该签名、缩写签（initials）、写日期的地方都填了
- [ ] 所有承租人（每个成年住户）都签了；业主一方所有产权人或授权人都签了
- [ ] 勾选框都选了，空白处填了或写 N/A
- [ ] 附件和附加条款（addenda）都在、都签了，名称和主合同里引用的一致
- [ ] 金额、日期、地址在各文件之间一致
- [ ] 双方都拿到了完整的副本
